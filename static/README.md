# static/ — recursos das telas (js, css, imagens, fontes)

Pasta servida em `/static/...` pelo backend. O auto-update entrega arquivos daqui (js, css, json, svg, png, jpg, ico, woff/woff2),
desde que estejam listados em `arquivos_online.json`. Use para bibliotecas de gráficos e identidade visual dos painéis de TV,
assim as telas funcionam sem depender da internet.
